# samples

Длинные тексты для ручной проверки ридера: скорость, паузы на пунктуации, переходы по предложениям, сохранение места.

`prince-and-the-pauper-ru.md` — «Принц и нищий» Марка Твена в переводе Иеронима Ясинского, 33 главы, около 58 000 слов.
Источник: Викитека. Текст в общественном достоянии (Марк Твен умер в 1910, Ясинский — в 1931).

Как пользоваться: открой файл в Obsidian и запусти команду `Speed Reader (RSVP): Speed read entire active note`.
