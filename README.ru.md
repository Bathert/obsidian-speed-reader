# Speed Reader (RSVP) для Obsidian

Скорочтение по одному слову за раз (RSVP): подсветка точки оптимального распознавания (ORP), регулируемая скорость, умные паузы, чанкинг, оглавление, запоминание места, статистика и озвучка системным голосом или через облако Unreal Speech. Нужен Obsidian 1.13.0 или новее. Текущая версия: **1.3.4**.

[English version](README.md)

## Возможности

### Чтение и отображение

- **Одно, два или три слова в кадре**, с опциональным bionic-выделением внутри чанка.
- **Подсветка ORP**: настраиваемый цвет и ширина зоны от одной до трёх букв.
- **Рамка «The Redicle» (35/65)**: фокусная буква стоит на 35% от левого края, поэтому длинные окончания не выталкивают слово из вида. Есть режим «строго по центру» (50/50).
- **Нелинейные тайминги по длине слова**: очень короткие слова (1–2 буквы) показываются на 20% быстрее, средние (3–8) — обычно, длинные (9–12) — на 15% медленнее, экстра-длинные (13+) — на 35% медленнее.
- **Метки фиксации** сверху и снизу рамки, можно отключить.
- **Адаптивное окно**: рамка, отступы и шапка масштабируются по высоте окна Obsidian, поэтому слово, полоса прогресса и кнопки не обрезаются в невысоком окне.

### Темп и ритм

- **Плавный разгон (Speed Ramp-up)**: старт с 65% целевой скорости и выход на неё за первые слова.
- **Авто-откат на паузе**: несколько слов назад, чтобы не терять контекст; откат считается только по словам, прочитанным с последнего старта, и не накручивает статистику.
- **Паузы на знаках препинания, абзацах, числах и аббревиатурах** с настраиваемыми множителями.
- **Режим «Тренер»**: каждые N прочитанных слов повышает целевой WPM до заданного потолка.
- **Итоги паузы**: прочитанные слова, реальная средняя скорость, ускорение против 200 WPM, сэкономленное и оставшееся время, короткая мотивационная строка.

### Навигация и фокус

- **Оглавление**: в шапке ридера список всех заголовков заметки, текущая глава подсвечивается автоматически; по списку можно прыгнуть в любой раздел.
- **Чтение с курсора**: команда запускает всю заметку со слова под курсором редактора; для выделения есть пункт контекстного меню.
- **Хайлайт на лету** (`H` / `Р`): оборачивает текущее предложение в `==выделение==` прямо в заметке, а если редактора нет — копирует предложение в буфер.
- **Интерактивный контекст**: на паузе показываются 15 слов вокруг текущего, любое соседнее слово кликабельно для мгновенного перехода; во время чтения строка компактная.
- **Дзен-режим** (`F` / `А`): во время чтения приглушает шапку, контекст, полосу прогресса и кнопки; при наведении на окно возвращает их.
- **Статус-бар**: прогресс и оставшееся время активной заметки (`📖 42% · ~3 мин`), по клику открывается ридер.
- **Жесты**: на рамке чтения тап слева или справа — перемотка, тап по центру — старт/пауза, свайп вверх или вниз — ±25 WPM.

### Технические заметки: код, формулы, таблицы

- **Блоки кода** по умолчанию пропускаются, чтобы листинг не рвал ритм; включите «Читать код в заметках», чтобы читать их по словам. Маркеры ``` в поток слов не попадают.
- **Блочные формулы** (`$$...$$`, `\[...\]`) пропускаются. Короткая инлайн-математика (`$x$`, `$O(n)$`) читается как текст; длинные формулы не проговариваются по символам.
- **Таблицы** разворачиваются в ячейки: символы `|` в ридер не попадают, смещения слов сохраняются, каждая строка заканчивается короткой паузой.
- **Чистка Markdown**: комментарии Obsidian (`%%...%%`), HTML-комментарии, маркеры callout, сноски, голые URL (сокращаются до домена), хайлайты и разделители таблиц убираются; `snake_case` и сравнения вида `a < b` сохраняются.

### Язык интерфейса

- **Русский и английский интерфейс**: автоматически по языку Obsidian либо вручную в настройке «Язык интерфейса» (`auto`, `ru`, `en`).
- Кнопки ридера, подсказки, баннер продолжения, итоги паузы и уведомления следуют выбранному языку.
- **Определение языка для озвучки**: `ru-RU` или `en-US` по текущему предложению для системного голоса.

### Озвучка

- Кнопка динамика и клавиша `M` включают и выключают озвучку; скорость пропорциональна выбранному WPM.
- В настройках два движка:
  - **Системный (Web Speech)** — голоса ОС, работает офлайн; качество зависит от системы.
  - **Unreal Speech** — облачный API, нужен ключ из [unrealspeech.com/dashboard](https://unrealspeech.com/dashboard). Список голосов берётся из API (по умолчанию Amelia; есть Charlotte, Emily, Giulia, Lucía и другие). **Русского голоса в API нет**, поэтому русский текст звучит с акцентом.
- **Лимиты и надёжность Unreal Speech**: текст режется на куски не больше 1000 символов и отправляется последовательно с паузой 600 мс, чтобы не превышать лимит бесплатного тарифа в 2 запроса в секунду. Таймаут запроса — 20 секунд; одновременно в работе только одно предложение.
- **Счётчик символов**: в настройках видно, сколько символов отправлено из этого хранилища, есть сброс, кнопка «Проверить ключ» и команда «Test speech key».
- **Мягкий откат**: неверный ключ, исчерпанная квота, лимит запросов или сеть — причина сообщается один раз, дальше играет системный голос.
- Ключ хранится только в данных плагина этого хранилища (`data.json`) и никогда не попадает в репозиторий.
- Озвучка приблизительная, не пословная; облачные голоса могут обращаться к онлайн-сервисам — учитывайте это для чувствительных заметок.

### Прогресс, курсор, статистика

- Место чтения запоминается для каждой заметки и сохраняется во время чтения, на паузе и при закрытии. Если ридер открыли и сразу закрыли, ничего не прочитав, прошлое место не затирается.
- При закрытии курсор в редакторе переходит на прочитанное слово; смещение ограничивается длиной документа, поэтому параллельные правки не ломают переход.
- **Статистика скорочтения**: прочитанные слова, время, максимальная скорость и оценка сэкономленного времени против 200 WPM. Это оценка, а не гарантия понимания.

### Шрифты для чтения

- `Golos Text` — крупный x-height, открытые апертуры, полная кириллица и латиница; основной вариант для русских текстов.
- `Atkinson Hyperlegible` — различимые формы букв, но **без кириллицы**: для русских слов браузер подставит другой шрифт, поэтому он годится только для латиницы.
- Шрифты встроены в `styles.css` как data URI, в сеть ничего не уходит. Лицензии OFL лежат в `fonts/`.
- Выбор шрифта: **Настройки → Speed Reader (RSVP) → Шрифт ридера**. По умолчанию — шрифт темы.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Space` | Старт / пауза (с авто-откатом) |
| `M` / `Ь` | Вкл / выкл озвучку |
| `↑` / `↓` | ±25 WPM |
| `←` / `→` | Перемотка на настроенное число слов |
| `[` / `]` | Предыдущее / следующее предложение |
| `H` / `Р` | Выделить текущее предложение в заметке |
| `F` / `А` | Дзен-режим |
| `R` / `К` | Перезапуск с первого слова |
| `Esc` | Закрыть ридер (сохраняет прогресс и курсор) |

## 📦 Установка

Скачайте три файла из одного [релиза GitHub](https://github.com/Bathert/obsidian-speed-reader/releases) или соберите проект командами `npm ci` и `npm run check`.

1. Создайте папку `<Хранилище>/.obsidian/plugins/rsvp-speed-reader/`.
2. Скопируйте туда `main.js`, `manifest.json` и `styles.css`.
3. Перезапустите Obsidian и включите **Speed Reader (RSVP)** в **Настройки → Сторонние плагины**.
4. Если раньше плагин стоял в папке `obsidian-speed-reader`, отключите его, сохраните `data.json` и переименуйте папку в `rsvp-speed-reader`. `data.json` хранит настройки, место чтения и ключ Unreal Speech. Две копии одновременно не включайте.

## 🚀 Запуск

Откройте заметку, при необходимости выделите фрагмент и нажмите значок книги на левой панели. Либо через палитру команд (`Ctrl+P`):

- **Speed read current selection or active note** — выделение, если оно есть, иначе вся заметка;
- **Speed read selected text** — только выделение;
- **Speed read entire active note** — вся заметка;
- **Speed read from Cursor** — вся заметка со слова под курсором;
- **Show speed reading statistics** — счётчики;
- **Test speech key** — отправляет одно слово в Unreal Speech и сообщает результат или точную ошибку;
- **Run self-check** — открывает и закрывает пробное окно, проверяет разбор, смещения, тайминги, навигацию, границы прогресса и само окно, затем показывает, сколько шагов прошло.

Для выделенного текста в контекстном меню редактора есть пункт **Speed read selection**.

## ⚙️ Настройки

- **Статистика читателя**: слова, время, максимальная скорость, экономия времени; сброс счётчиков.
- **Язык**: язык интерфейса (авто / русский / английский).
- **Скорость и отображение**: WPM по умолчанию, шаг перемотки, тема окна, размер и шрифт, подсветка и ширина ORP, цвет ORP, метки фиксации, выравнивание Redicle, нелинейные тайминги, дзен-режим.
- **Темп**: разгон и его длина, «Тренер» с шагом, интервалом и потолком, итоги паузы, авто-откат и его длина, паузы на знаках, запятых, абзацах, числах и аббревиатурах с множителями.
- **Чанкинг**: слов в кадре, bionic-выделение.
- **Технические заметки**: чтение блоков кода.
- **Прогресс**: запоминать место, синхронизировать курсор при закрытии, показывать оценку в статус-баре.
- **Озвучка**: движок (системный / Unreal Speech), ключ, голос, счётчик символов со сбросом, проверка ключа, включение TTS.

Вкладка настроек использует декларативный API, поэтому её параметры находятся через поиск по настройкам Obsidian.

## Работа с сетью

По умолчанию плагин работает офлайн. Сеть используется только если в настройках выбран движок **Unreal Speech**: текущее предложение отправляется на `api.v8.unrealspeech.com` для синтеза аудио, больше ничего с устройства не уходит. Телеметрии, аналитики и рекламы нет. Ключ API хранится локально в данных плагина этого хранилища. С системным голосом плагин не делает сетевых запросов вообще.
